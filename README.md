## Stage-by-Stage Build Approach

This README is structured so I can share progress in stages while working on the design.

### Stage 1: Understanding the Layout

In this stage, I study the structure of the reference and identify the key sections:

- header/nav area
- hero/banner section
- card or content blocks
- buttons and CTAs
- spacing and visual rhythm
- image and text alignment

I am focusing on understanding how the design is broken into parent and child sections before writing the actual code.

### Stage 2: Building the Core Structure

Once the layout is understood, I will create the semantic HTML structure using containers and sections.

Key goals:

- keep the markup clean and readable
- create clear sections for each part of the design
- avoid unnecessary extra nesting
- set up the structure before styling details

### Stage 3: Applying Flexbox and Positioning

This is the main CSS stage of the project. I will use:

- `display: flex` for alignment and layout
- `position: relative` for parent containers
- `position: absolute` for overlay or aligned elements
- consistent spacing, paddings, and margins

The objective here is to make the page closely resemble the design while keeping the code practical and manageable.

### Stage 4: Refining Visual Details

After the layout is in place, I will refine:

- typography
- colors
- border radius
- spacing consistency
- proportions of elements
- image placement and sizing

This is where the page starts to feel closer to the original reference.

### Stage 5: Final Polish and Review

In the final stage, I will review the design for:

- alignment issues
- spacing mismatches
- broken layering
- responsiveness problems
- overall visual similarity to the reference

## Assignment Requirements
